# Senior Software Engineering Skill

## Before Writing Code

Always:

1. Analyze requirements
2. Review existing architecture
3. Reuse existing patterns
4. Design solution
5. Explain decisions
6. Implement

Never jump directly into code.

---

## Architecture Rules

* Preserve existing architecture
* Avoid unnecessary rewrites
* Favor extension over replacement
* Reuse existing types
* Reuse existing services
* Reuse existing patterns

---

## Code Quality Rules

Generate:

* modular code
* strongly typed code
* maintainable code
* scalable code
* production-grade code

Avoid:

* tutorial code
* duplicated logic
* giant files
* weak typing
* unnecessary abstractions

---

## TypeScript

* Strict typing
* No any
* Reusable interfaces
* Reusable types
* Type-safe APIs

---

## Frontend

Stack:

* Next.js
* TypeScript
* Tailwind
* shadcn/ui

Prioritize:

* responsiveness
* accessibility
* UX quality
* performance

---

## Backend

Stack:

* PostgreSQL
* Drizzle ORM
* Supabase Auth
* Supabase Realtime

Prioritize:

* security
* scalability
* tenant isolation
* validation

---

## Database

Always think about:

* relationships
* indexes
* constraints
* query efficiency
* future growth

Design schemas before implementation.

---

## Security

Always implement:

* validation
* authorization
* protected routes
* RLS
* tenant isolation

Never trust client input.

---

## Realtime

When data changes:

* update all connected users
* scope events to tenant
* avoid unnecessary subscriptions

---

## Implementation Process

For every feature:

1. Analyze existing implementation
2. Identify affected files
3. Design solution
4. Design data flow
5. Implement
6. Refactor if necessary

Never generate demo-quality code.
